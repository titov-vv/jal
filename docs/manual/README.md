# JAL User Manual

**JAL — Just Another Ledger — is a program that keeps track of your money.**

It runs on your own computer, stores everything in a single file that never leaves it, and answers
the questions that a bank app cannot: *where did the money go last month?*, *what is everything I own
worth today?*, *did that investment actually earn anything?*

This manual is written for someone who has just downloaded JAL and has never used an accounting
program before. You do not need to know bookkeeping, and you do not need to be a programmer.
Read the first four chapters in order — after that, take whichever chapter matches what you want to do.

## A note about the pictures

Every screenshot in this manual comes from a made-up household: a person living in Munich with a
bank account, a card, some cash, a small trading account and a savings deposit. The names, numbers,
prices and dates are invented for the manual. Your own JAL will show your own data in the same places.
